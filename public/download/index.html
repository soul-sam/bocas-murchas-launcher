O launcher do grupo, pra Windows.

Baixar para Windows

Windows 10 ou 11 · 64 bits

O instalador é pra PC com Windows. No celular, dá pra usar direto pelo navegador.

Como instalar

  1. Abra o arquivo baixado.
  2. Se o Windows mostrar “O Windows protegeu o computador”, clique em Mais informações e depois em Executar assim mesmo.
  3. Pronto. Daí em diante o launcher se atualiza sozinho.

Prefere não instalar? Use pelo navegador.
